# 사용자 녹화 가이드 — Nunchikochi 데모 영상 (한국어)

이 문서는 **사람 출연·실제 웹캠 시연 구간**을 사용자가 직접 찍는 방법입니다(U5: 출연·목소리는 사용자 결정).
얼굴이 나오지 않는 데모·라이브(가짜 카메라) 화면은 `web/tools/record_demo.mjs`가 대신 녹화하므로,
여기서는 ① 실제 웹캠으로 시연하는 장면과 ② (원하면) 인트로·아웃트로 출연 장면만 직접 녹화하면 됩니다.

대본·장면 순서는 [`SCRIPT.md`](SCRIPT.md) · [`SHOTLIST.md`](SHOTLIST.md), 자막은
[`captions.en.srt`](captions.en.srt)를 쓰세요. 전체 길이는 **5분 이하**(목표 4분 30초)입니다.

---

## 1단계 — 준비
- **환경**: 밝은 곳(얼굴이 아니라 자세 데모라도 화면이 선명해야 함), 조용한 공간, 데스크톱/노트북 1대.
- **브라우저**: Chrome 또는 Edge 최신 버전(카메라 권한 허용 필요). 다른 탭·알림은 닫아 깔끔하게.
- **화면 녹화 도구**: macOS는 `Shift+Cmd+5`(화면 기록), Windows는 `Win+G`(Xbox Game Bar) 또는 OBS Studio.
  1280×800 이상, 30fps 권장. 소리(내레이션)를 넣을 거면 마이크 입력을 켜세요.
- **대본 준비**: `SCRIPT.md`의 §1·§3·§8을 직접 말할지(출연), 보이스오버만 할지 미리 정합니다.
- **민감정보 주의**: 화면에 **액세스 키·AWS 계정 ID·이메일**이 보이지 않게 하세요(키 입력란은 가려짐).

## 2단계 — 라이브 URL·키 입력
1. 제출 문서(Devpost)에 적힌 **공개 라이브 URL**을 엽니다(없으면 심사자 안내대로). 로컬로 할 거면
   `scripts/run_local.sh`로 띄운 뒤 `http://127.0.0.1:8099`를 엽니다.
2. 첫 화면에서 **Live (your camera)** 를 선택합니다.
3. **Access key** 칸에 제출 문서의 키를 붙여넣습니다. 이 키는 **메모리에만** 저장되고 기기·URL·로그에
   남지 않습니다(그래서 입력칸이 가려진 password 형태입니다).
4. 상태 줄에 **Connected · Running on arm64 · OpenCV 5…** 가 뜨는지 확인합니다(서버 연결·런타임 표시).
   안 뜨면 잠시 후 다시 시도하거나, 영상용으로는 **Demo 모드**로 전환해도 됩니다.
5. 동의 체크 후 **Start session** 을 누릅니다. (키 입력 순간은 녹화에서 잘라내도 됩니다.)

## 3단계 — 시연 순서 (약 90초, SHOTLIST §3·§6 기준)
1. **보정(5초)**: 화면을 바라보고 가만히 — 중립 자세를 학습하는 장면.
2. **오버레이 켜기**: "Show what OpenCV sees" 를 켜서 얼굴 상자·랜드마크 점이 뜨는 것을 보여 줍니다
   (좌표만, 영상은 화면 밖으로 안 나감 — 내레이션으로 강조).
3. **넛지 유도**: 화면 쪽으로 몸을 기울여 몇 초 유지 → "sit back a little" 넛지가 뜹니다(최대 2개).
4. **에이전트 패널**: "Agent activity" 를 열어 결정 타임라인과 **second_look**(다시 본 뒤 결정) 행을 보여 줍니다.
5. **자세 인형 시연(약 30~40초)**: 실행 화면의 "자세 인형(Posture buddy)" 패널로 내려가 다음 순서로 보여 줍니다.
   인형은 **앉아 있는 상체 모양**(머리·목·어깨·가슴·팔·손, 다리는 책상 아래라 안 그림)입니다. 패널 맨 위의
   고지 문구("머리와 손은 측정한 값, 목과 몸통은 모델로 추정해요. 다리는 그리지 않아요.")를 한 번 비춰 줍니다.
   ① 고개를 좌우로 천천히 기울이면 인형 머리가 같은 방향으로 기울어집니다(움직임은 보기 쉽게 약 1.5배 과장됨).
   ② 화면 쪽으로 고개를 **앞으로 빼면** 머리가 앞으로 나오고 몸통이 **추정으로** 살짝 숙이며 색이 주황으로 바뀝니다(거북목).
   ③ 물을 한 모금 마시면 **측정된 물 마시기 이벤트**로 오른팔이 입 쪽으로 올라갔다 내려옵니다.
   ④ "Side(옆)" 버튼으로 옆모습에서 거북목을 확인하고, "바른 자세 고스트"를 켜 **연한 하늘색 윤곽**과 비교합니다.
   ⑤ 바르게 고쳐 앉으면 인형이 다시 가운데·초록으로 돌아옵니다. 마지막으로 **Rewind 슬라이더**를 드래그해
      "이 시점부터 앞으로 나왔다"를 되감아 보여 줍니다(주황색 표시 구간). **측정(머리·손) vs 추정(목·몸통)** 구분을
      말로도 한 번 짚어 줍니다 — 어깨·몸통·다리는 측정하지 않습니다.
6. **실패 장면(권장)**: 조명을 어둡게 하거나 얼굴을 가려 품질 경고가 뜨게 하고, second_look 후에도
   해소되지 않아 **사람에게 묻는** 토스트가 뜨는 것을 보여 줍니다(정직한 한계 — SCRIPT §8).
7. **종료→리포트**: "End session" → 집계 카드·요약 리포트(리포트 화면에도 인형 되감기가 있습니다). 한국어 전환도 한 컷.

## 4단계 — 녹화 도구 (얼굴 없는 화면은 자동)
- **얼굴 없는 화면**(데모·라이브 가짜 카메라)은 아래로 자동 녹화합니다(사람 녹화 불필요). 데모 녹화에는
  **자세 인형 구간**(고개 기울임→앞으로+몸통 추정 숙임→물 마시기 팔 올림→옆모습+고스트→되감기)도 포함됩니다:
  ```bash
  # 정적 서버 띄우고
  python3 -m http.server 8099 --directory web
  # 데모 녹화 (카메라 없음)
  node web/tools/record_demo.mjs --base http://localhost:8099 --out docs/video/recordings
  # 로컬 라이브 녹화 (가짜 카메라, 서비스 필요: scripts/run_local.sh)
  SVC=http://127.0.0.1:8000 KEY=<로컬 더미 키> \
    node web/tools/record_demo.mjs --live --base http://localhost:8099 --out docs/video/recordings
  ```
  결과 webm은 `docs/video/recordings/`에 저장되며 **저장소에 커밋하지 않습니다**(.gitignore 처리됨).
- **실제 웹캠 출연·시연**은 이 가이드 2·3단계대로 **본인 화면 녹화 도구**로 직접 찍습니다.
- 편집은 선호하는 도구(iMovie·CapCut·DaVinci Resolve 등)로, `SHOTLIST.md` 순서에 맞춰 이어 붙이고
  `captions.en.srt` 자막을 올립니다.

## 5단계 — 업로드·공개 설정
- 유튜브/Vimeo 등에 올리고 **공개 또는 미등록(Unlisted)** 으로 설정합니다(대회 요건: 공개/비공개 링크 제출 가능).
  미등록이면 링크를 가진 심사자만 볼 수 있습니다.
- **5분 이하**인지, **팀/사람·앱·아키텍처·결과**가 모두 보이는지 확인합니다(SCRIPT 체크리스트).
- 화면에 **키·계정 ID·실명 이메일**이 없는지 마지막으로 다시 확인합니다.
- 최종 링크를 Devpost 제출 폼의 영상 칸에 넣습니다.

---

### 자주 겪는 문제
- **카메라 권한이 안 뜸**: 주소창 왼쪽 자물쇠 → 카메라 허용, 새로고침. HTTPS 또는 localhost에서만 동작합니다.
- **상태 줄이 'unavailable'**: 서버가 아직 배포 중일 수 있습니다. Demo 모드로 녹화하거나 잠시 후 재시도.
- **녹화 스크립트가 playwright 없다고 함**: `npx playwright install chromium` 후 다시 실행.
  그래도 안 되면 브라우저 탭을 화면 녹화 도구로 직접 찍으세요(데모는 자동으로 진행됩니다).
